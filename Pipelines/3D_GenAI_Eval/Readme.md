# 3D GenAI Evaluation Pipeline

This pipeline evaluates 3D models generated by AI systems against ground truth using a suite of geometric and visual similarity metrics. It aligns AI-generated meshes with real-world references, computes per-metric scores, classifies them, and produces annotated visualizations.

---

## Directory Structure

```
project/
├── data/
│   ├── gt/              # Ground truth meshes (e.g., keyboard.ply)
│   └── ai/              # AI-generated meshes (e.g., keyboard.obj)

├── results/

│       ├── after_scaling.png
│       ├── after_icp.png
│       ├── <metric>_vis.png / .json

│
├── loader.py
├── preprocessing.py
├── refiner.py
├── visualizer.py
├── main.py
```

---

## Evaluation Process

1. **Loading (loader.py)**: Loads `.ply` and `.obj` meshes. Performs validation.
2. **Preprocessing (preprocessing.py)**: Normalizes and orients meshes.
3. **Safe Scaling (refiner.py)**: Uses volume, convex hull, or bounding box fallback to align sizes.
4. **ICP Alignment (refiner.py)**: Aligns meshes using point-to-point ICP.
5. **Evaluation (metrics/)**: Runs metric-specific evaluations.
6. **Visualization (visualizer.py)**: Generates alignment overlays and 3D comparisons.

---

## Metric Modules

Each metric is implemented in `metrics/` with a shared interface from `metrics/base.py`. All results are classified using thresholds in `constants.py`.

- **Chamfer Distance (chamfer.py)**: Average distance between sampled points.
- **Earth Mover's Distance (emd.py)**: Measures minimal transport cost between point sets.
- **IoU (iou.py)**: Uses boolean or voxel intersection.
- **Hausdorff Distance (hausdorff.py)**: Max point-to-surface distance.
- **Normal Consistency (normal_consistency.py)**: Angle similarity between normals.
- **Mean Curvature Error (mean_curvature_error.py)**: Compares surface curvature between points.

> Each metric outputs:
> - Score (float)
> - Classification string: e.g., "excellent", "good", "poor"

---

## Metric-Specific Details

- **Chamfer Distance**: Uses 5000 sampled points. Saves bidirectional distances.
- **EMD**: Employs Hungarian algorithm. Saves matched visual pairs.
- **IoU**: Chooses between voxel-based or boolean method depending on watertightness.
- **Normal Consistency**: Uses matched sampled points and visual heatmaps.
- **Mean Curvature**: Curvature estimated via PCA across 30 neighbors.

> All visualizations follow: **Red = GT**, **Green = AI**.

---

## Outputs

Each model in `results/<model_name>/` includes:
- `metrics.json`: Per-metric results
- `before_scaling.png`, `after_scaling.png`, `after_icp.png`
- `<metric>_vis.png`: Error overlays per metric

> A global `summary.json` can optionally aggregate all evaluations.

## Running the Pipeline

1. Place ground truth meshes in `data/gt/` and AI-generated ones in `data/ai/`.
2. Run:
```bash
python main.py
```
3. Review results under `results/<model_name>/`

## Notes

- Each mesh is rescaled using multiple fallbacks (volume → convex hull → bbox diagonal).
- Visualizations sample 5000 points per mesh.
- Meshes are assumed to be manifold and properly scaled.
- Classification logic defined in `metrics/base.py → get_class()`.
- Visualization stages include before/after scaling and ICP.

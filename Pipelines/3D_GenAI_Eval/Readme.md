# 3D GenAI Evaluation Pipeline (Updated)

This pipeline evaluates 3D models generated by AI against ground truth references using geometric metrics and visualization. It includes automatic alignment (center → scale → refine), a wide set of metrics, error handling, and detailed result outputs.

---

## Directory Structure

```
project/
├── 3d_data/
│   ├── gen_ai_models/              # AI-generated meshes (e.g., keyboard.obj)
│   ├── internet_gt_models/        # GT meshes from the internet (.obj)
│   └── linemod_gt_models/         # GT meshes from Linemod (.ply)
│
├── results/                       # Outputs by method/category/timestamp/model
│   └── <method>/<category>/<time>/<model>/
│       ├── before_scaling.png
│       ├── after_scaling.png
│       ├── after_icp.png
│       ├── <metric>_vis.png / .json
│       └── metrics.json
│
├── pipeline/
│   ├── config.py
│   ├── loader.py
│   ├── preprocessing.py
│   ├── refiner.py
│   ├── visualizer.py
│   └── metrics/
│       ├── base.py, chamfer.py, emd.py, iou.py, hausdorff.py, etc.
│
├── main.py
└── summary.json
```

## Evaluation Pipeline

1. **Pairing**

   * Finds AI-GT mesh pairs using name heuristics and folder traversal
   * Matches `.obj` AI files with `.obj` or `.ply` GT files from either source

2. **Loading**

   * `loader.py`: Robust loading using `trimesh`, supports list, Scene, and Trimesh formats

3. **Preprocessing**

   * `preprocessing.py`:

     * Centers both meshes
     * Applies **safe scaling** using:

       1. Volume (if watertight)
       2. Convex hull volume (fallback)
       3. Bounding box diagonal (last resort)

4. **Refinement**

   * `refiner.py`:

     * RANSAC alignment using FPFH features
     * Two-stage ICP refinement (20mm coarse, 5mm fine)

5. **Visualization**

   * `visualizer.py`:

     * Red = GT, Green = AI
     * Outputs: `before_scaling.png`, `after_scaling.png`, `after_icp.png`
     * Optional interactive mode with `ENABLE_VISUALIZATION = True`

6. **Metrics** (from `metrics/`):

   * All implement `compute()` and optionally `get_class(score)`
   * Metrics used:

     * `IoUBoolMetric`, `IoUVoxelMetric`
     * `ChamferMetric`, `HausdorffDistanceEvaluator`
     * `NormalConsistencyEvaluator`, `MeanCurvatureEvaluator`, `EMDEvaluator`

7. **Error Handling**

   * Per-metric `try-except` blocks avoid full run failure
   * Each model's result is saved regardless of partial failures

## Output Artifacts

For each model:

```
results/<method>/<category>/<time>/<model>/
├── before_scaling.png
├── after_scaling.png
├── after_icp.png
├── chamfer_vis.png, emd_vis.png, etc.
├── metrics.json
```

Additionally:

* `summary.json`: list of all model results
* All metric visualizations follow Red=GT, Green=AI convention

---

## Metric Overview

| Metric               | Unit        | Description                              |
| -------------------- | ----------- | ---------------------------------------- |
| IoU (boolean/voxel)  | % overlap   | Volume-based shape match                 |
| Chamfer Distance     | mm          | Avg bidirectional surface distance       |
| Hausdorff Distance   | mm          | Max deviation between surfaces           |
| Normal Consistency   | Cosine sim. | Angle similarity between surface normals |
| Mean Curvature Error | mm⁻¹        | Local curvature shape preservation       |
| Earth Mover's Dist.  | normalized  | Point distribution alignment cost        |

## How to Run

1. Place GT and AI models as follows:

```
3d_data/
├── gen_ai_models/<method>/<category>/<time>/<model>.obj
├── internet_gt_models/*.obj
└── linemod_gt_models/*.ply
```

2. Run:

```bash
python main.py
```

3. View results in the `results/` folder or inspect `summary.json`

## Notes

* Classification thresholds defined in `config.py`
* Metric logic in `metrics/*.py`, thresholds in `config.py`
* Visual overlays saved as `.png`, numeric scores as `.json`
* Works with both watertight and non-watertight meshes
* Results always saved, even on partial errors
